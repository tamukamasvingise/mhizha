# Mhizha

Offline Android app for construction service providers (plumbers, builders, electricians and similar trades): customers, quotations, invoices, receipts.
Planning stage: the map is `.scratch/mhizha-v1/map.md`. Read it first.

- Terms: `GLOSSARY.md`. Tracker: `docs/agents/issue-tracker.md`. Research notes: `docs/research/`.
- Reference designs are kept outside this repo; the owner's agent notes say where. Never add them here.
- Use pnpm, never npm. Read the owner's machine tools list before installing anything.
- Never commit client records, backups, client designs or signing keys. Never name the reference user.
- Public repo, GPL-3.0. Issues only; no outside code.
